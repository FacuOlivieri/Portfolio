Sistema de gestión para un bazar real: ventas, stock de productos, clientes, cupones de descuento y resumen del día. Usuarios con roles y permisos, login con JWT y API REST por capas en Spring Boot, consumida por un frontend en React. Desplegado con Docker Compose y Nginx.
